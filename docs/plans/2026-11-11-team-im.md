# 团队 IM

团队 IM 面向共用一套服务的内部团队。账号、会话、消息、附件、未读和授权由独立的 IM 服务管理。Web 与 Electron 共用客户端。成员加入后可使用人与人私聊和群聊，群主可邀请服务器 Agent。

消息和投递记录同事务写入。客户端通过有序事件游标恢复实时连接。消息内容、附件及事件依据当前成员关系授权。人类可查看完整的群历史。Agent 从加入时开始读取，群成员可以通过引用显式分享更早消息。

每个 Agent 绑定持有独立的 DSH Session 和工作卷。IM 调度器负责授权和任务状态，Runner 使用 DSH 公开接口执行。群内先解析显式提及，再处理引用 Agent 回复，最后由可选的 Super Agent 分类普通人类消息。分类只有忽略或选择一个 Agent 两种结果。

使用新数据库部署。人员归属未知的旧聊天记录留在原数据目录。原版 DS Bot Web 的侧栏直接列出同事和团队会话。点击同事打开私聊。原版新建菜单提供团队群聊，可同时选择同事和 Agent。DS Bot 客户端复用 IM 服务的账号、数据和实时事件。个人 Bot、连接器、工具和电脑操控沿用 DS Bot 的界面、登录和权限。群主可把自己在原版创建的 Agent 加入群，成员显式提及或引用该 Agent 后，由 Agent 的所有者在团队消息中批准。打开的本机网页用已有 Runner 事件协议转交任务，原版 DS Bot 以群绑定为单位打开独立会话，再把完成的文本送回 IM。原版工作区和团队会话各自保留自己的历史。

部署与验收命令见 [团队 IM 运行说明](../../team/README.md)。
