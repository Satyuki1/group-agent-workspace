# 已确认的设计方向

## 外层界面

沿用用户认可的 V2 清爽简约视觉：左侧聊天列表、中间多人多 Agent 群聊、白灰底色、少量红色强调。左侧与聊天区不重新设计。

## 右侧工作面

用户最新修正：直接使用 DeepSeek Harness 的原生右侧界面。右侧关联当前群的 Group Agent 工作空间，由群成员共同使用。

不再沿用 V3 自行设计的云电脑外壳、“接管操作”、控制者/观看者状态或模拟 macOS 桌面。这些不是用户要求复用的 Harness 原生界面。

核查的原生结构：

- 右侧面板没有独立标题行；标签栏就是面板顶部。
- 标签栏容纳已打开资源、添加、分栏、全屏和折叠控件。
- 文档预览、工作区文件、浏览器等由已启用的 Harness 插件提供；不自行改成一组“文件／任务／电脑”产品分类。
- 文件直接在工作面里显示，保持原生路径、预览和导航方式。
- 群共享是产品对工作区的归属和访问设计；不在原生工作面叠加解释性标语。
