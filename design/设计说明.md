# 群聊共享工作区 · 第一版

当前产物是图像模型生成的静态设计稿，不代表已经实现下列交互。

## 信息结构

- 左侧约 20%：搜索、全部/群聊/Agent 筛选、置顶与最近会话、账号入口。
- 中间约 39%：群标题、成员、固定目标、多人多 Agent 消息、文件卡片、输入框。
- 右侧约 41%：当前群的共享工作区，文件/任务/浏览器/终端标签，可打开多个成果。
- 右下方：当前任务与执行 Agent、进度、暂停和详情入口。

## 关键交互意图

1. 切换会话时，右侧切换到该群的工作区，并记住各群上次打开的文件和标签。
2. 点击聊天文件卡片，在右侧打开对应文件，聊天滚动位置保持不变。
3. 真人与 Agent 都显示为群成员；Agent 通过小型 AI 标记及角色名称区分。
4. 长任务进度集中在工作区，群消息只保留交接、结果及需要人处理的事项。
5. 工作区支持折叠、调整宽度与展开；群聊输入始终可达。
6. 同一 Agent 的文件更新、任务状态和群内发言使用一致身份，便于追踪来源。

## 视觉意图

浅灰侧栏、白色内容面、细边框与蓝色强调。绿色表示完成，桃色用于设计 Agent 的角色识别。聊天选中态轻量，避免大色块压过会话内容。

图中的人员、消息、文件、进度均为演示内容。正式实现时应使用真实任务状态；无法计算百分比的任务展示阶段与用时。
